Notofit JP

Outfit と Noto Sans JP を合成した、Web 向けの和欧混植フォント。
Noto Sans JP を使っているページを、font-family の差し替えだけで置き換えられます。

日本語と English が、ひとつの設計で並ぶ。

使い方

npm、または CDN から読み込みます。

npm install notofit-jp
/* npm */
@import "notofit-jp/notofit-jp.css";

/* CDN */
@import url("https://cdn.jsdelivr.net/npm/notofit-jp@0.1/notofit-jp.css");

読み込んだら、次の3つを指定します。

body {
  font-family: "Notofit JP", sans-serif;
  text-autospace: normal;   /* 和欧間のアキ */
  font-kerning: normal;     /* 約物の隣接処理 */
}

後ろ2つは既定では効きません。text-autospace は多くのブラウザで初期値が no-autospace のため、font-kerning は Firefox が既定で和文に適用しないためです。

ウェイト単位で読む

全ウェイトを読み込む必要がなければ、ウェイトごとの CSS があります。

@import "notofit-jp/400.css";
@import "notofit-jp/700.css";

unicode-range で125個に分割してあるため、どちらの場合もページが実際に ダウンロードするのは使用文字に対応する十数個だけです。

ウェイト

Regular（400）と Bold（700）の2つです。

700 — Bold

欧文側は、和文と見かけの太さが揃う位置で作っています。 Outfit をそのまま 400 / 700 で使うと和文より太く見えるため、少し細い位置を選んでいます。

組版について

1. 欧文の大きさと位置を、和文に合わせてある

和文が基準です。欧文を拡縮し、ベースラインを動かして和文に揃えています。 CSS の size-adjust では大きさしか変えられず、ベースラインは動かせません。 合成する理由がここにあります。

2. 隣り合った約物のアキを取り除く

和文の約物は「半角の字形＋二分アキ」でできています。単独ならこれで正しいのですが、 約物が隣り合うとアキが二重になります。重なった分だけを取り除いています。

単独で現れる約物は全角のままです。詰めるのは隣接したときだけで、 font-feature-settings: "palt" のように一律には詰めません。

3. かなと全角英数をプロポーショナルにする

全角固定をやめ、字面に応じた幅にしています。字面そのものの大きさは変えていないため、 文字が小さくなったようには見えません。

4. 和欧間のアキは CSS に任せる

日本語と欧文の間のアキは text-autospace が担当します。 pre や code の中では自動的に無効になるなど、文脈に応じた処理が CSS 側の仕様として用意されているため、フォントには入れていません。

プロパティ何が起きるか
font-kerning: none約物の隣接処理が無効になります

font-feature-settings の palt / halt / chws、size-adjust、ascent-override、 text-spacing-trim は指定しても効果がありません。字幅と縦メトリクスは フォント側で確定しているためです。
