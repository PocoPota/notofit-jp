Notofit JP

欧文の Outfit と和文の Noto Sans JP を、 ひとつのフォントに合成した Web 向けの和欧混植フォントです。

和文を基準に、欧文の大きさ・ベースライン・コロン類の高さを合わせています。 約物は隣り合ったときだけ詰まり、かなと全角英数はプロポーショナルです。

行の高さと単独の約物の字送りは Noto Sans JP と一致するため、 置き換えとして使えます。ウェイトは 400 と 700、横書き専用。 SIL Open Font License 1.1。

現在 0.1.0 の試用段階です。 実際のページでの表示は確認していますが、使用例がまだ少なく、 字送りなどの設計値が変わる可能性があります。

単独で現れる約物は全角のままです。日本語組版では、それが正しい字送りにあたります。
Chromium はブラウザ側でも同じ処理を行うため、2行目と3行目に差が出ます。 Safari と Firefox にその処理はなく、どちらも3行目の状態になります。 Notofit JP はフォント側で処理するため、どのブラウザでも同じ結果になります。

Get started

npm install notofit-jp
@import "notofit-jp/notofit-jp.css";

body {
  font-family: "Notofit JP", sans-serif;
  text-autospace: normal;
  font-kerning: normal;
}

Google Fonts が Noto Sans JP に使っているのとほぼ同じ区切りでサブセット化しています。 ページが読み込むのは、使った文字を含むサブセットだけです。 CDN は cdn.jsdelivr.net/npm/notofit-jp から利用できます。

仕様、指定する CSS、ブラウザごとの挙動、置き換えたときの変化は 利用ガイドにまとめています。
